# 使用说明

适用版本：0.1.0 开发预览，Windows + Chrome，英语视频。

## 当前电脑

项目位于 `E:\GitHub\YouTubeLocalSubtitles`，本地依赖、模型和构建后的扩展已准备好。首次使用不必重新下载模型。

1. 双击项目中的 `Start.cmd` 启动服务。停止服务使用 `Stop.cmd`。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择 `E:\GitHub\YouTubeLocalSubtitles\dist`。
4. 打开 [本机设置页](http://127.0.0.1:18765/setup)，点击“连接 Chrome 扩展”。
5. 刷新正在观看的 YouTube 视频页。

本机设置页只用于配对，不会播放音频。服务也不会自行开始录音或识别。

## 看视频时

播放器右上角会显示“本地字幕”按钮，普通窗口和全屏都能找到。

- 选择“英文”“中文”或“双语”。选择会保存在本机。
- 无字幕时，点击“开始本地字幕”；在 Chrome 共享框中选择**当前 YouTube 标签页**，开启**共享标签页音频**。
- 已有字幕时默认不运行识别。人工字幕和 YouTube 自动生成字幕都算已有字幕，即使 CC 按钮关闭也一样。
- 想替换现有字幕，勾选“已有字幕或无法判断时，仍使用本地识别”，然后开始。
- 双语模式先显示英文，再补中文；中文模式需要等待翻译。英文模式不提交翻译任务。
- 点击“停止本地字幕”或 Chrome 的“停止共享”会释放音频捕获。

普通播放的声音由你正在观看的视频控制；本地服务没有语音朗读功能。扩展不会为了检测而自动播放一个视频。

首次识别和首次翻译需要加载模型，首条字幕会比后续字幕慢。当前冷启动测试首条英文约 10 秒、首条双语约 14 秒；这是受控素材结果，不保证每个视频相同。

## 自动启停的范围

“自动”发生在你已启动的有效共享会话内。切到有字幕的视频、播放广告或字幕状态不明确时，暂停本地推理；满足条件后恢复。

暂停视频会结束当前语音分段，已说完的内容仍可完成识别。快进、倒退、换视频或倍速变化会丢弃旧位置的待显示结果。

Chrome 新标签页、完整刷新、浏览器停止共享或离开页面后，可能需要重新开始并授权。不要把共享框中“整个屏幕”或其他标签页选作音源；当前版本会拒绝无法核对的目标。

备用入口是 `Alt + Shift + L` 或扩展工具栏按钮，使用定向标签页捕获。快捷键可在 `chrome://extensions/shortcuts` 修改。页面按钮是已完成集成验证的主入口，备用入口仍需在日常 Chrome 环境进一步验证。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| 页面没有按钮 | 确认已加载 `dist`，刷新普通 `/watch` 视频页；Shorts 和嵌入页不在首版范围 |
| 提示尚未配对 | 启动服务，在本机设置页点击连接，再刷新 YouTube |
| 共享后提示没有音频 | 重新选择当前标签页并打开“共享标签页音频” |
| 无法核对共享目标 | 选择当前标签页；如果浏览器不支持所需能力，可尝试备用快捷键 |
| 无法判断字幕 | 等待片刻，或明确勾选强制识别；默认不会把未知当成没有字幕 |
| 翻译不可用 | 可以先切换英文；检查 `logs` 里的服务与翻译诊断日志 |
| 翻译暂时跟不上 | 过旧任务会被跳过，避免落后越来越多；降低倍速或切换英文 |
| 更新后状态异常 | 在扩展管理页点“重新加载”，再刷新 YouTube；必要时重启本地服务 |
| 本机设置页打不开 | 运行 `Start.cmd`；默认端口为 18765，翻译端口为 18766 |

## 重新安装或在其他电脑使用

运行 `Install.cmd`。它会安装项目依赖、构建 `dist`、下载固定版本模型与 llama.cpp CUDA 运行时，并验证 SHA-256。需要 uv、Node.js LTS、Windows x64 和支持 CUDA 12.4 运行时的 NVIDIA 驱动。

大文件、模型、运行时及缓存放在项目目录下。下载中断时重新运行安装脚本可续传。项目约需数 GB 空间，建议预留 10GB 以上余量。

当前版本没有安装器、开机启动、托盘和 Chrome 商店自动更新。首次加载扩展需要你手动完成一次。

## 本地与隐私

音频只送往本机服务，中文翻译也在本机完成。默认不保存音频或字幕历史，不启用麦克风，不抓取整个系统声音，也不把个人配置提交到 GitHub。

`config.local.json` 包含本机配对信息，不要公开分享。`work`、`runtime`、`logs`、`cache`、`models` 均由 Git 忽略。服务仅监听回环地址，不提供局域网访问。

## 目前限制

这是开发预览，核心链路已经在受控浏览器验证，尚未完成真实 YouTube 的 20 分钟连续观看和正式质量验收。只把英语音轨作为验证范围；其他语言、重叠人声、音乐与强噪声可能识别不准。

字幕检测依赖 YouTube 页面内部数据，网站更新后可能需要适配。当前时间范围按语音段估算，不提供词级精确对齐。详细证据见 [验证记录](VERIFICATION.md)。
